# BrickBreaker
A simple 2D Brick Breaker game made with Unity.
## Features
- Paddle movement
- Ball physics
- Brick breaking system
- Basic game mechanics
## Technologies
- Unity (2D)
- C#
## Project Status
This project is a beginner-level game project.
